# AO Strength Team - Charity Giving: Registration and Monthly Routine

## How it works

AO Strength Team gives 10% of every purchase back to the body of Christ. At checkout, the buyer selects one of four charities; that choice is recorded in Stripe metadata on the order (Stripe account `acct_1TYvV0DhKzM9Hkbe`). Each month (or quarter) Pete runs the ledger script to tally what is owed to each charity, then donates those amounts manually via each charity's direct donation URL. All giving is manual - no auto-pay, no subscription billing, no accounts created on Pete's behalf. Pete controls the timing and amount.

> **Note:** No accounts, subscriptions, or payments have been created automatically. Every signup and every gift is Pete's to complete.

## Monthly giving routine

1. Run the ledger script from the website repo root:
   ```
   node scripts/tithe-ledger.mjs --since <YYYY-MM-01>
   ```
   Replace `<YYYY-MM-01>` with the first day of the month being closed (e.g. `2026-06-01`).

2. Open the generated statement in `operations/tithe-statements/` - it shows exactly how much 10% is owed to each charity based on Stripe sales and buyer selections for that period.

3. Donate the listed amount to each charity via its direct URL above. Use a credit card or ACH - no accounts are required for one-time gifts at any of the four charities.

4. Download or screenshot each donation receipt and save it to `operations/tithe-statements/` alongside the month's ledger statement. Name files in the format `YYYY-MM-<OrgShortName>-receipt.pdf` (e.g. `2026-06-compassion-receipt.pdf`).

5. Repeat monthly or quarterly depending on cash flow preference. All four charities support one-time and recurring giving - no penalty for batching quarterly instead of monthly.
